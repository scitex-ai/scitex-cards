THE PICKER IS THE SDK's. When the host registers a project provider, {% templatetag openblock %} scitex_project_picker {% templatetag closeblock %} renders the canonical selector and this page adds no second one. Only a STANDALONE mount (no host provider) falls back to the plain form below, which offers exactly the projects the viewer's own authorized cards name — the same set the provider would answer with, so the two can never disagree. STATES ARE DISTINCT ON PURPOSE: no-project, denied, unavailable, empty and filtered-empty each need a different action from the reader, and the HTTP status matches (403 denied, 503 unavailable).
